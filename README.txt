SKAUTING ZAGORJE — NOVA VERZIJA
Datoteke: index.html, style.css, script.js.
Nova stranica koristi svjetliju zelenu pozadinu nogometnog terena i ne sadrži zasebne stare odjeljke pod naslovima „Razvoj karijere” ili „Stručni tim”. „Povezivanje s klubovima” prikazano je samo jednom u početnom redu pogodnosti, kao na referentnoj slici.

OBJAVA NA GITHUB PAGES:
1. Raspakirajte ZIP.
2. U istom GitHub spremištu idite na Code > Add file > Upload files.
3. Prenesite index.html, style.css i script.js iz raspakirane mape (ne ZIP kao jednu datoteku).
4. Kliknite Commit changes.
5. Settings > Pages > Source: Deploy from a branch > Branch: main > Folder: /(root) > Save.
6. Pričekajte nekoliko minuta i kliknite Visit site.

Da se stari sadržaj ne bi prikazivao, zamijenite postojeće datoteke u ISTOM spremištu koje objavljuje stranicu. Ovaj ZIP sam po sebi ne mijenja već objavljenu stranicu. Obrazac otvara korisnikov program za e-poštu; poruka se ne šalje automatski.
